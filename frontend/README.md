# ГИС-терминал и рабочие контуры

```bash
# Из корня репозитория: установить зависимости backend (Python 3.11+)
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt
cd backend
OFFLINE=true ../.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8001

# В другом терминале; Node.js 22.12+
cd frontend
npm ci
npm run build
npm run test:e2e
# Опционально, при установленном Chromium или Chrome:
CHROMIUM_PATH=/path/to/chromium npm run test:mobile
# После тестов запустите сервер разработки:
npm run dev
```

Vite слушает `0.0.0.0:5173` и проксирует `/api`, `/docs` и `/openapi.json` на FastAPI `127.0.0.1:8001` **на сервере разработки**. Браузер использует относительные URL. Токен и API-ключ хранятся только в памяти вкладки. Для ЕДДС/МИС допустим JWT администратора/диспетчера либо ключ `EDDS_MIS_API_KEY`; без конфигурации ключа анонимный доступ не работает.

Базовый SVG-слой (русло, водохранилище, округа, дороги) **схематичен**, не представляет реальные границы и не подходит для навигации или землеустройства. Полигоны, расчётное поле, справочник районов, погода и прогнозы загружаются из API; происхождение и источники показаны в интерфейсе. Фильтры меняют только отображение очагов, но не состав источников шлейфа. Мини-график для очага относится к ближайшему району. Время для клинической вкладки берётся из настройки на ГИС-карте. При недоступности сервера отображается ошибка.

Наряд формируется из **повторного** серверного ранжирования доступных участков с ограничениями выбранных бригад: его состав может отличаться от результата калькулятора. Точка контура — демонстрационная подстановка, а не фактический GPS. После закрытия наряда и импорта данных обновляются общие расчёты. Сброс данных с подтверждением удаляет все наряды, но не удаляет сохранённые фото. Telegram/SMS могут оставаться неотправленными; отображается реальный статус шлюза.

`npm run test:e2e` запускает собранное приложение в JSDOM и отдельный FastAPI с **временной базой**, проверяя все четыре вкладки, реальные multipart-запросы и межвкладочную синхронизацию; данные основного стенда тестом не меняются. Для запуска нужен backend в `../.venv` или путь к Python с зависимостями в `BACKEND_PYTHON`. Это не визуальный браузерный тест.

Модель не клинически валидирована. Информационные материалы не заменяют врача. Встроенные данные синтетические, а загруженные файлы не верифицируются автоматически. Не используйте стенд для реальных персональных данных или решений; см. `backend/README.md`.

`test:mobile` дополнительно использует установленный Chromium (его puppeteer-core не скачивает), проверяет 360/390/430 px, формы и два печатных представления на изолированной БД; `MOBILE_ARTIFACT_DIR` может сохранять тестовые PDF. Без Chromium этот тест не запускается.
